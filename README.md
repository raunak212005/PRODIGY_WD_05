# Prodigy InfoTech Web Development Internship - Task 05

## 📌 Project Overview
This repository contains the completion of **Task 5** for the **Web Development Internship** at **Prodigy InfoTech**. The objective was to develop a **Weather Web Application** that fetches real-time weather data from a weather API based on the user's current location or a user-entered city. The application displays essential weather information through a clean, responsive, and user-friendly interface.

## 🛠️ Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling & Responsive Design)
* **JavaScript (ES6)** (API Integration & Interactivity)
* **Weather API** (Real-time Weather Data)

## ✨ Features Implemented
* Search weather by **city name**.
* Fetch weather using the user's **current location**.
* Display **current temperature**, weather condition, humidity, wind speed, and location.
* Weather icons based on current conditions.
* Responsive design for desktop, tablet, and mobile devices.
* User-friendly interface with smooth animations.
* Error handling for invalid city names and API responses.

## 📊 Project Functionality
1. **Location-Based Weather:** Retrieves the user's current location and displays real-time weather information.
2. **City Search:** Allows users to search weather details for any city worldwide.
3. **Weather Information:** Displays temperature, weather condition, humidity, wind speed, and other relevant details.
4. **Dynamic Weather Icons:** Shows weather icons based on current conditions.
5. **Responsive Layout:** Optimized for desktops, tablets, and mobile devices.

## 📁 Files in this Repository
* `index.html` – Structure of the weather application.
* `style.css` – Styling and responsive layout.
* `script.js` – API integration and application logic.
* `README.md` – Project documentation.

## 🎯 Learning Outcomes
* Learned how to integrate third-party APIs using JavaScript.
* Worked with asynchronous programming using `fetch()` and Promises.
* Implemented geolocation functionality for location-based weather.
* Improved DOM manipulation and dynamic content rendering.
* Enhanced responsive web design and user experience.
* Gained experience in handling API errors and displaying real-time data.
